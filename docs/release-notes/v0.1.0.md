Flood's first independent design-system release for React and TypeScript, with
Next.js App Router support.

- Eight original components: Button, Input, Textarea, Checkbox, Radio, Switch,
  Field and Link. No third-party UI component library or Tailwind dependency.
- Semantic tokens, light/dark themes, native form controls and visible focus.
- CLI installation, dry-run planning, version diagnostics and matching agent guides.
- A Next.js example and a minimal landing page with interactive component samples.

```sh
npx @flood-md/cli@0.1.0 init
```

Run inside an existing npm-based React/Next.js project, then import
`@flood-md/react/styles.css` once at the app root. Read the installed
`flood/DESIGN.md` for component usage and Next.js client boundaries.

Validation: TypeScript, ten unit/contract tests, installation from real package
tarballs, production Next.js build, and eight desktop/mobile browser tests covering
forms, hydration, keyboard use, themes and automated accessibility checks.

This is a small foundation release. The installer supports npm, preserves existing
files, and leaves the application stylesheet import explicit. No automatic source
rewriting, copied-component update engine or project theme editor is included.
