Pointer и keyboard

Hover: 450 ms. Focus: 120 ms. Escape скрывает только tooltip.

Исключения — это часть системы

Agent: используем Flood blob/identity вместо generic robot.
State marks: checkbox mixed, radio dot, circle/square — геометрия, не поиск «похожей» Heroicon.
Provider: GitHub/Telegram/Figma показывают свои logos; Heroicons описывают действия рядом, а не заменяют identity.
