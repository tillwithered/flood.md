# Boolean controls — 0.6.4

[Индекс](README.md) · [превью](recipes/boolean-controls.html) · [проверки](recipes/boolean-checks.md) · 2026-09-19.

**Candidate: P-01/P-02/P-03.** Владелец поручил продолжать DS после исправлений 0.6.3. Это разрешение на следующую итерацию и публикацию, не одобрение ещё не просмотренных форм и состояний. Компаунды отложены. Основа light/dark, Heroicons Solid, двухслойный focus и запрет системного chrome сохраняются.

## Что теперь можно проверить

Один рабочий пример на каждый примитив плюс таблицы значений и состояний: **24 checkbox, 16 radio, 22 switch**. Таблицы статичны и подписаны; в них нет имитации интерактивных ARIA-controls. Сочетания focus/hover/error показаны отдельно. Невозможный native disabled+focus не добавляется ради прямоугольной таблицы. Это не все возможные комбинации и не сертификат доступности.

Три новых файла `boolean-controls.html/css/js` подключают неизменённый `primitives-refined.css` из 0.6.3. В автономном HTML те же файлы встроены. Новых palette/focus colors, runtime dependencies, шрифтов, сети и записей в приложение нет. Рабочее внедрение — отдельная задача; нельзя импортировать весь lab в Svelte.

## P-01 · Checkbox: независимые значения и охват группы

Видимый квадрат 18×18, R5, border1. Галочка Heroicons Solid — 12px slot, mixed-line — 10×2. Между квадратом и подписью10. Label target minimum36; coarse pointer44. Вторая строка начинается под названием; отметка у первой строки, не по центру многострочного блока. Readonly-checkbox не придумываем: boolean readonly не является native HTML-состоянием.

Native input сохраняет checked/indeterminate, label и Space; скрывается только его системный внешний вид. Собственный mark aria-hidden. Не использовать button/div вместо настоящего поля ради иконки. Состояние mixed задаётся DOM property, не строковым атрибутом. Никакого смешивания этой семантики с отметкой завершения задачи без отдельного контракта.

**Пример «Все доступные поля»:** мастер контролирует только три enabled child IDs. Недоступная стоимость явно исключена. 0 из3 = off, 1–2 = mixed, 3 = on. Mixed→all, all→none. Нет тайного восстановления прошлой частичной комбинации. Scope написан рядом; «Все» не распространяется на скрытые проекты/задачи.

Валидация требует хотя бы одно доступное поле только в этом демонстрационном сценарии. До submit ошибки нет. После ошибки input values сохраняются, текст связан с группой; восстановление выбора снимает ошибку. Ошибка не превращает всю группу в красную карточку. Disabled имеет читаемую причину рядом и исключён из Tab; общую opacity на label/описание не ставить.

## P-02 · Radio: одно значение, не немедленная запись

Круг18, border1, dot8, gap10 и тот же label target. Dot сохраняет центр независимо от длины подписи. Native `name` объединяет группу; fieldset/legend объясняют вопрос. Клик/Space/стрелки выбирают значение, Tab покидает группу. Стрелки пропускают disabled. Не добавлять второй JS-алгоритм поверх работающего native управления.

Нулевой первоначальный выбор показан намеренно. При submit без выбора ошибка относится к группе; фокус переходит к первому доступному радио, не выставляя ему checked. В данном примере изменение — draft до «Применить в демо». Не вводить такой дополнительный commit во все радио-настройки автоматически: владелец значения определяется сценарием.

Выбранность = dot; keyboard position = независимый двухслойный focus. Не добавлять к ним автоматически жирную подпись, боковую полосу и заливку всего label. У радио нет mixed. Selected+disabled и selected+error показаны отдельно: ошибочное/недоступное состояние не стирает значение.

## P-03 · Switch: confirmed, requested и operation раздельны

Track36×20; border1+padding1 = видимый inset2; thumb `20−2×2=16`; ход `36−2×2−16=16`. Размеры и положение вычисляются из связанных CSS variables. Off и on имеют одинаковый border-box. Track — капсула, thumb — круг; это отдельный shape contract, не механическое вычитание радиуса любой внешней секции.

Стабильная подпись называет настройку. On/off обозначены положением и нейтральным контрастом, не зелёным/синим accent. Native checkbox с role=switch сохраняет checked и Space. Для него нет mixed и не дублируется конфликтующий aria-checked. SVG-галочка и radio-dot в switch не нужны.

| Событие | Видимое значение | Доступное действие |
| --- | --- | --- |
| Покой | Последнее подтверждённое | Включить/выключить |
| Pending | Пока прежнее; рядом статус операции | Повторная запись заблокирована, focus остаётся |
| Успех | Подтверждённое новое | Следующее изменение |
| Явная ошибка | Прежнее; причина рядом | Повторить captured requested value |
| Ответ потерян | Последнее подтверждённое + явная неопределённость | Сверить, не повторять mutation |
| Сверка | Прежнее до результата чтения | Запись не отправляется |
| Disabled | Последнее известное, если оно есть | Причина, без Tab/активации |

В pending используется aria-disabled с явным guard на click/Space, а не native disabled, выбрасывающий клавиатуру из текущего input. Статическая недоступность использует настоящий disabled. При retry/reconcile скрываемая кнопка передаёт focus переключателю. Обычное завершение, в том числе на скрытой вкладке, не переносит focus само.

Таймер700ms и outcomes — **локальные fixtures**, не производственная задержка или сеть. Пример unknown моделирует успешную запись с потерянным ответом; readback подтверждает её без второй mutation. Другие ошибки сверки, конфликт версий, offline и отмена операции не реализованы. Нельзя выводить поддержку реальных API/permissions из этой демонстрации.

## Общие слои состояния

Rest: без shadow, bevel и нижнего штриха. Для необходимого контура checkbox/radio используется существующий boundary, а не почти невидимый decorative edge. Focus — прежние core1/halo4 с нулевым X/Y/blur; у native input второй контур отключён, ring рисует один mark. При invalid розовый border и neutral focus сосуществуют, label/ошибка остаются читаемыми.

Hover/pressed меняют тон, но не stroke width, вес текста, размеры или позицию. На on/mixed применяется только смешение существующих ink/panel (90% и82% ink); это кандидаты feedback, не новая палитра. При disabled не стирать mark, значение или причину.

Forced colors: собственные shapes используют Canvas/CanvasText/Highlight/HighlightText/GrayText; no shadow, отдельный системный outline. `forced-color-adjust:none` ограничен геометрическим mark с явно системными цветами, не отключает пользовательскую палитру всей страницы. Reduced motion убирает ход/вращение, не текст операции. SR/целевые WebView требуют отдельной проверки.

## Подписи и измерения

Вкладка «Подпись и геометрия» измеряет реальные rect: checkbox18/R5, gap10, label target, track36×20/thumb16, inset2 на обоих концах. Длинная подпись увеличивает target, не mark. Диагностические области нажатия доступны отдельной кнопкой, не являются UI-decoration.

Однострочная подпись20px даёт optical top offset1 у checkbox18. Сначала выравнивание относительно первой строки, затем измерение с настоящим Golos в приложении. Fallback font в автономном HTML не доказывает совпадение его метрик. Включение подсказки не добавляет новый внешний контейнер к каждому контролу.

## Связь с источниками

Проверены [WAI checkbox](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/), [radio](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) и [switch](https://www.w3.org/WAI/ARIA/apg/patterns/switch/): семантика, клавиатура и стабильная подпись. Они не задают наши цвета и размеры. Native начальный Shift+Tab у пустой радиогруппы может отличаться от ARIA-примера; не обещать идентичность браузеров без проверки.

Linear: [public launch 2020-06-30](https://linear.app/changelog/2020-06-30), [refresh 2026-03-12](https://linear.app/now/behind-the-latest-design-refresh). Релевантность — плотная рабочая среда с настройками, не доказательство современности каждого capture.

Mobbin просмотрен 2026-09-19: [Notifications](https://mobbin.com/screens/915c51c8-1e36-47d7-a8e9-a2c33bcc98f2) и [Pulse](https://mobbin.com/screens/c320e5d5-6a91-48bb-9ebf-192f78780948). Видны группы настроек, label/helper и switches. Переносим связь подписи с её настройкой, не синие controls, sidebar или card layout. Точная capture date неизвестна: provisional. Это не checkbox state sheet и не свидетельство реального pending behavior. Скриншоты в репозиторий не копировались.
