# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:

[Report a vulnerability](https://github.com/tillwithered/flood.md/security/advisories/new)

Include the affected version, a minimal reproduction, impact and any suggested
fix. Do not include passwords, tokens, customer data or unrelated project files.
Avoid public issues for unpatched vulnerabilities. If the private report form is
unavailable, wait until a private channel is available rather than posting exploit
details publicly. There is currently no guaranteed response-time commitment.

## Scope and updates

Reports may concern the public packages, installer, website or release tooling.
Security fixes target the latest release; maintained older release lines will be
listed here if introduced. Use the release changelog when planning an upgrade.

Public source is intentional. Credentials and account-specific configuration are
not part of the product. A private repository is not a secret store either.
Do not put secrets in source files, agent instructions, examples or issues.
