# Flood brand materials

Read docs/ui/brand-and-notices.md and the relevant approved feedback/iconography contracts.

Use raster blobs only as accent, empty-state illustration or stable Flood/agent identity. Do not use asset color as Warning/Danger/Success semantics and do not replace Heroicons with blobs.

Inside semantic notices use the contextual notice-action recipe, not a nested neutral/white secondary surface. Preserve the independent two-layer focus.

Do not modify src/assets/flood-material masters, .flood exports or runtime FloodGlyph mappings unless the task explicitly requests production migration.
