Flood 0.1.1 publishes the full release train from GitHub Actions using npm trusted
publishing and provenance. The CLI archive preserves Unix executable permissions;
the initial Windows-staged 0.1.0 archive contained the same entry contents with a
different file mode. The installer, agent guides and website now target 0.1.1.

Run inside an existing React or Next.js npm project:

```sh
npx @flood-md/cli@0.1.1 init
```

Then import `@flood-md/react/styles.css` once at the app root. React component APIs
are unchanged. Upgrade all Flood packages together and compare agent guide changes
with any project-specific instructions before editing existing files.
