---
name: flood-ui
description: Build React and Next.js interfaces with the installed Flood design system. Use for Flood components, themes, forms and layout composition.
---

Read `flood.json` and `flood/DESIGN.md` from the project root first. Run
`npx @flood-md/cli doctor` to check versions. Import only published APIs from
`@flood-md/react`; use its styles once in the application entry. Follow the installed
design guide for composition, accessible forms and Next.js client boundaries.
Do not replace project instructions or introduce another UI library.
