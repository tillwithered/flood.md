# Flood 0.2.5

The dark base library grows from 57 to 87 original React components. All four
packages remain aligned at 0.2.5. Registry availability is verified separately
from source; use matching package versions and installed agent instructions.

- Forms and selection: NumberInput, Slider, Combobox, Tag, MultiSelect,
  SearchInput, PasswordInput, FileInput, ListBox, PinInput, Rating, Dropzone and
  CharacterCount. Native forms, labels, read-only/disabled states and local
  selection behavior stay explicit; uploads and remote data belong to the host.
- Overlays and feedback: AlertDialog, Drawer, CopyButton and ToastRegion reuse
  Flood actions, scrolling, focus and layer behavior. Drawer supports four edges;
  toast timing pauses while hovered, focused or the document is hidden.
- Content and composition: AvatarGroup, StatusIndicator, Figure, Blockquote,
  InlineCode, Metric, Timeline, NavigationList, Steps, Section, Split, Center
  and SkipLink. Section heading level and visual size are independent.
- Nine additive floating-material roles bring the semantic profile to 193 roles.
  Floating menus use quiet translucency and a light shadow, with opaque and
  forced-color fallbacks. Existing semantic token values remain unchanged.
- Generated API references, live recipes, Markdown and agent composition guidance
  cover the additions. Previews keep stable geometry and a quiet dotted canvas.
- The website reuses Flood clipboard actions and SkipLink. Its public pages are
  prerendered from the same React tree, with generated metadata and sitemap.

Install or upgrade all Flood packages together. Existing public APIs remain
available. Localize action and status labels. Check the documented limitations
before using complex selection or overlays in an application.
