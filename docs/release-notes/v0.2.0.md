# Flood 0.2.0 — base dark design system

Release candidate. Registry publication has not been verified.

This version adds a usable dark foundation through `FloodRoot`: 154 semantic
roles, locally bundled Inter, relative sizing, typography/layout primitives and
native form controls. Button supports seven sizes and a filled subtle variant.
Input/Textarea retain native HTML sizing separately from their visual controlSize.
Field connects required labels, hints, errors and external description IDs.

The `/team` Next.js example composes the actual package into settings and member
management. Its data stays in the browser and resets on reload; it sends no
invitations or save requests. The existing `/foundations` fixture covers core
geometry and interaction states.

Import the same stylesheet and wrap a new interface in `FloodRoot`. Existing
interfaces outside the root retain the legacy 0.1.x themes and overrides.
Foundation roles use their separate `--flood-sys-*` namespace. Keep all four
Flood package versions aligned. Existing customized agent files are preserved;
review the 0.2.0 instructions rather than overwriting them during an upgrade.

The new foundation profile supplies dark only. Focus uses a configurable pink
default. A new light profile, complex overlays and material effects are outside
this base release. Token stability is recorded in the generated manifest.
