# Flood 0.2.6

Fix Breadcrumb word wrapping in Firefox-based browsers, including Zen. The
separator's automatic minimum inline size could consume a fraction of a pixel
from the next label and force its final character onto another line. Remove
that minimum while preserving the existing gap and ordinary wrapping behavior.

Grid, Stack and Pagination now have coverage across Chromium, Firefox and WebKit,
including scaling, narrow layouts, RTL and long labels. No public API or token
values change. All four Flood packages remain aligned at 0.2.6.
