# Flood 0.2.2 — marketing composition

Adds `Heading size="display"`, `Text size="lead"` and `CodeSnippet` for commands and short examples.
The snippet takes a required code string and optional host-owned action; it
does not request clipboard permissions or perform network operations itself.
The display, lead and monospace roles expand the dark profile to 163 semantic roles.
Existing heading sizes, token values and APIs retain their behavior.

The website demonstrates these additions in a one-page composition with a
local workspace form and ideas list. Form changes and added ideas disappear
on reload; no project data is sent to Flood.

This is a compatible addition in the pre-1.0 0.2 stabilization series. Upgrade
all Flood packages together to 0.2.2, compare customized agent instructions and
run your host application's checks. The profile remains dark only.
