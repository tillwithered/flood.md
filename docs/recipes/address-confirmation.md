# Address confirmation

Use Autocomplete with an editable address. Selecting a suggestion fills the corresponding fields and leaves them open to correction. Ask for a decision when the delivery validator returns a meaningfully different address. Show the changed fields and let people keep their entry, accept the suggestion or return to editing.

The application chooses its provider and local postal fields. Match each response to the street query it was requested for. Cancel superseded requests or discard their responses. The application decides when a validation difference warrants review. Keep the typed draft while a request is pending or when it fails. Send the accepted address once and show success after the write succeeds. Send address data only to the providers the application has configured for the flow.
