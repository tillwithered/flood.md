- Normal archive member: `web/InterVariable.woff2`
- Italic archive member: `web/InterVariable-Italic.woff2`
- Font internal version: `Version 4.001;git-9221beed3`
- Variable axes: weight 100–900; optical size 14–32.
- SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`
- Italic SHA-256: `e564f652916db6c139570fefb9524a77c4d48f30c92928de9db19b6b5c7a262a`

The full upstream font includes Cyrillic; it has not been subsetted or converted.
The original `LICENSE.txt` is copied verbatim from the same release archive.
Both assets supply weight 100–900 and optical size 14–32, including Flood's 400/500
roles. CSS registers separate normal and italic faces under Inter; native em/i
content uses the real italic asset instead of synthetic slant. Both files include
Latin and Cyrillic and retain the same unmodified upstream license.
