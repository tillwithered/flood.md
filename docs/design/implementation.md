# Runtime UI kit and Quiet Workbench migration

Updated: 2026-09-20. Quiet Workbench anchor implementation resumed from the handoff. The production route now also uses the selected outer-shell treatment and a real-data R02 Home composition; broader flows and native visual acceptance remain separate work. Evidence below applies only to the named working-tree slice and does not certify every existing screen. Read [the handoff](handoff.md) and the current [design QA record](../../design-qa.md) before continuing code work.

Shared tokens and eighteen Svelte components are implemented in the working tree. They now cover the shell, shared controls, notices, modal framing, project/task rows and the main recovery actions used by the production UI. **Native visual acceptance is pending** until actual Tauri captures and interaction traces are recorded below. The broader component/flow matrices remain specifications; a successful startup or browser fixture does not complete the whole application redesign.

## Foundation ownership

| Artifact | Role |
| --- | --- |
| [src/design/tokens.json](../../src/design/tokens.json) | Single authored source, token version 1.2.0: light/dark roles, scales, declared contrast pairs, notes and registered legacy brand exceptions |
| [src/design/tokens.css](../../src/design/tokens.css) | Generated runtime output imported by [src/styles.css](../../src/styles.css) |
| [Specimen CSS](generated/tokens.css) | Generated from the same source; no independently authored palette |
| [Token reference](generated/token-reference.md) | Derived values, purpose notes and measured contrast pairs |
| [Former candidate path](tokens.target.json) | Generated compatibility pointer and migration provenance, without token values |
| [Generator/checker](../../scripts/design-contract.mjs) | Validation, generation, drift detection and foundation ownership check |

The initial palette uses neutral equal-channel grays and tested semantic pairs. The old light danger pair failed 4.5:1; its replacement passes the declared checks. The faint/pressed pair was also corrected before adoption. Danger controls now have separate hover/pressed surfaces and a danger focus halo; fields use a two-layer focus boundary/halo. Typography, focus, meaningful boundaries, control sizes, shape, motion and layers now have shared roles.

The initial foundation migration preserved the 720px column, existing page gutters and 304/58px sidebar. Quiet Workbench now selects a roughly 224px sidebar and separate 880–960px list/720px reader roles; actual values and native evidence must be recorded for the new implementation. The legacy 1160px content role is retained. Three existing gradient variables are documented compatibility exceptions, not permission to introduce gradient controls or replace raster blobs. Remaining local literals and old selectors are migration debt, not an additional approved token system.

## Implemented component entry points

Import the kit through [src/components/ui/index.ts](../../src/components/ui/index.ts). These are shared Svelte components, not a second runtime framework. Parent surfaces continue to own data, saving, versions and side effects.

| Component | Contract family | Current behavior / usage boundary |
| --- | --- | --- |
| [UiButton](../../src/components/ui/Button.svelte) | C03 | Primary, secondary, quiet and confirmation-danger variants; compact/default sizes; native button; busy state retains its label and prevents repeated activation. Caller owns the operation. |
| [UiIconButton](../../src/components/ui/IconButton.svelte) | C03 | Required accessible action label; decorative icon snippet; disabled/busy state and a shared focus treatment. |
| [PageHeader](../../src/components/ui/PageHeader.svelte) | C02 | Heading, optional description/count/mark and a separate action group; wraps with long content. A custom title snippet must preserve meaningful heading semantics. |
| [SectionNav](../../src/components/ui/SectionNav.svelte) | C08 | Named navigation with `aria-current`, ordinary button keyboard behavior and horizontal scrolling that reveals focused items. This is page/section navigation, not an ARIA tab widget. |
| [EmptyState](../../src/components/ui/EmptyState.svelte) | C21 | Compact title, optional explanation/icon and action snippet. Caller distinguishes an empty collection from loading or a failed read. |
| [InlineNotice](../../src/components/ui/InlineNotice.svelte) | C21/C22 | Info, success, attention and danger treatment; optional title/actions; announcements are opt-in. Caller preserves drafts and supplies an actual recovery action. |
| [TaskRow](../../src/components/ui/TaskRow.svelte) | C10 | Task title, explicit urgency/completion text, legacy semantic glyph and optional metadata. Open action is separate from an optional completion checkbox and auxiliary actions. Checkbox mutation exists only when the caller supplies `oncomplete`. |
| [MaterialRow](../../src/components/ui/MaterialRow.svelte) | C14 | One native object-opening button with persistent rounded geometry, optional icon, description and access/version metadata. A row does not contain a second editor or nested button. |
| [UiTextField](../../src/components/ui/TextField.svelte) and [UiTextArea](../../src/components/ui/TextArea.svelte) | C04 | Persistently labeled filled fields with a low-emphasis resting boundary, strong focus/invalid feedback and retained draft value. |
| [SelectField](../../src/components/ui/SelectField.svelte) | C06 | Product-owned select-only listbox with a custom trigger/popover, selected marker, outside/Escape dismissal, typeahead, Arrow/Home/End navigation and focus return. It replaces the remaining native select in the create flow; large searchable catalogs still belong in a focused modal. |
| [SegmentedControl](../../src/components/ui/SegmentedControl.svelte) | C07 | Native radio group. Its 12px outer radius, 4px inset and 8px inner radius follow `inner = outer − inset` rather than subtracting the inset twice. |
| [ButtonGroup](../../src/components/ui/ButtonGroup.svelte), [ToggleButton](../../src/components/ui/ToggleButton.svelte), and [Switch](../../src/components/ui/Switch.svelte) | C03/C07 | Related action grouping and native toggle/switch semantics with shared neutral states. |

Component styling consumes foundation roles. Functional micro-motion now covers shared modal entry, project-context/settings section changes, home overflow menus, task-card hover/press feedback and create-choice feedback. It uses the authored 100–180 ms motion roles, avoids idle animation and becomes static for both OS and application reduced-motion settings. Forced-color and reduced-motion support in code still require real environment checks; their presence is not a pass record. Parent layouts own spacing between components.

The remaining production stylesheet has now been normalized to the authored geometry and typography scales: routine controls use `--radius-control`, opening rows use `--radius-action-row`, compound surfaces use `--radius-panel`, circular/capsule shapes use `--radius-pill`, and UI text uses the regular/medium/strong weight roles. Legacy one-off values from 5–18 px and intermediate weights such as 570/630 are no longer an alternative runtime system. Nested panel recipes continue to use `--panel-inner-radius` where the outer/inset relationship is explicit.

## Development gallery and specimen

The [development entry](../../src/main.ts) selects the Svelte kit gallery when `import.meta.env.DEV` is true and the URL has `?ui-kit`. `theme=light|dark` now selects the specimen theme deterministically. The gallery is organized by foundations, controls, working patterns and recovery states rather than by a decorative component dump. It exercises the same component files and generated tokens used by the anchors, with synthetic examples rather than project storage.

The standalone [HTML specimen](preview.html) is the historical composition from before the Quiet Workbench selection, with local synthetic interactions. Use [the selected direction](quiet-workbench.md) for the current composition. It now uses the same generated token values, but it does not replace the Svelte gallery, native window or production workflow checks. Neither a specimen screenshot nor the development query is proof that files were saved or an integration worked.
