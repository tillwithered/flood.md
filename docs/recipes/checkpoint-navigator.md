# Navigate review checkpoints

Use a checkpoint list when users can jump among sections while tracking which ones are answered and which to revisit. Let the host own current section, saved answers, and flags. These states can overlap. A current checkpoint can be answered and flagged.

Use one named action to open each checkpoint. Make the flag an independent toggle with its own focus target. Keep the list order stable as flags change. If the product shows a before-submit summary, link unresolved checkpoints back to their sections and preserve the answers entered so far.
