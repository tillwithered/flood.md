# Flood 0.2.1 — icon geometry

IconSlot centers its children, and the website uses a real Lucide Plus SVG
instead of a text character. The icon follows the existing relative size and
remains centered as the host root font size changes. This corrects presentation
without changing component APIs or token values.

Keep Flood package versions aligned at 0.2.1 when upgrading. The website's
Lucide dependency is not added to the component package. Consumers continue to
supply their own licensed SVG artwork through IconSlot/IconButton.
