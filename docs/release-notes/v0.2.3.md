# Flood 0.2.3 — base components and agent guidance

This release expands Flood to 37 original React/TypeScript components and 168
semantic roles. The foundations profile remains neutral dark, with bundled Inter,
relative sizing, quiet boundaries and an accent focus indicator.

- Forms: Select, Label, Fieldset, RadioGroup, CheckboxGroup and InputGroup;
  error/warning/success/info feedback, visible read-only states and hidden-label
  options preserve native accessible names, values and form behavior.
- Actions: connected ButtonGroup, Toggle, ToggleGroup and SegmentedControl;
  native Link can opt into the same appearances and sizes as Button.
- Content and navigation: ScrollArea, Collapsible, Accordion, Tabs, Breadcrumb
  and Pagination. Tooltip, Popover and Dialog use original behavior and modern
  native browser APIs. See their guides for browser and state ownership contracts.
- Agent bundle: a short task router, rules matrix and focused references,
  including spacing/density/nested geometry guidance installed by the CLI.
- Website: grouped searchable catalog, live component recipes, matching TSX and
  canonical Markdown, local syntax highlighting and a shared Flood-based shell.

## Updating from 0.2.2

Upgrade all Flood packages together to the same exact version. Import Flood CSS
once and use FloodRoot for dark foundations. Existing component signatures and
legacy theme scopes remain supported; new APIs require the matching declarations.

Compare customized agent files with the new package sources before adopting
updates. The CLI deliberately refuses to overwrite existing owned files or
follow linked destinations; do not delete project guidance to force installation.
See [installation](../installation.md) and [agent setup](../agents.md).

UI behavior remains local: no data backend, hosted runtime, agent execution,
other framework adapter or new light foundations profile is introduced.
