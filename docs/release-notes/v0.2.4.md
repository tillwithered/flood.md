# Flood 0.2.4 · source candidate

Compatible additions in the pre-1.0 stabilization series: Badge, Spinner,
Skeleton, Avatar, Progress, Meter, Alert, DescriptionList, Table, Menu, Toolbar, Kbd, Card, Container, Grid, VisuallyHidden, AspectRatio, Image, List and EmptyState bring the catalog to 57 original components. All packages
are aligned at 0.2.4; registry publication is not implied by this candidate.

- Badge supports independent semantic tones, subtle/outline variants and sizes.
- Spinner supports named status or decorative presentation. Button loading uses
  the same indicator without changing Button's public API or accessible name.
- Skeleton reserves configurable geometry and remains hidden from assistive
  technology. Reduced motion disables the loading animations.
- Avatar preserves its size through image loading, failure and source changes,
  with initials or a supplied text fallback and optional decorative presentation.
- Sixteen additive semantic roles separate accent text from focus and loading fills
  from action colors. The dark profile now contains 184 public roles. Existing
  role values remain unchanged.
- Generated component pages, Markdown, live controls and versioned agent guidance
  cover each addition. A combined example is available at `/playground/content`.

Keep all four Flood packages aligned when upgrading. Existing 0.2.3 applications
retain their current APIs. Avatar requires a name; localize Spinner's standalone
label. Loading regions and data fetching remain host-owned.

Progress/Meter distinguish task completion from bounded measurements and support explicit labels/units. Alert defaults to static messages, with opt-in polite/assertive announcements. Breadcrumb natural-width wrapping is corrected while preserving touch targets and long-label reflow.

DescriptionList retains native term/description groups with container-responsive layout. Table preserves native captions and header/cell relationships, with density, logical numeric alignment and horizontal Flood scrolling. Data formatting and richer table behavior remain host-owned.

Menu adds action-menu semantics, keyboard navigation, typeahead, explicit disabled/danger states and row-action examples. Destructive action content has its own semantic color role, bringing the profile to 184 roles.

Toolbar adds directional action navigation; Kbd adds native key hints. Three relative keycap height roles bring the dark profile to 184 public roles. No actual shortcut bindings are installed.

Card composes Surface into an optional header/body/footer structure, with density, wrapping actions and heading levels. Existing semantic roles are reused; Card does not become an interactive wrapper.

Structural and accessible atoms add responsive containment, grids, reserved media geometry, native lists/images and focus-revealing nonvisual content. Checkbox adds a native indeterminate prop. Shared components reuse public Button/Link/IconSlot/ScrollArea/VisuallyHidden primitives. Normal and italic Inter are bundled. Layout and keyboard edge fixes preserve protected scroll gutters, modified keys and RTL switch geometry.
