# Inter font asset

`InterVariable.woff2` is an unmodified third-party font by the Inter Project
Authors, distributed under the [SIL Open Font License 1.1](LICENSE.txt).
It is not original Flood artwork. Retain the license with redistributed copies.

- Official source: <https://github.com/rsms/inter/releases/tag/v4.1>
- Archive: <https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip>
- Archive member: `web/InterVariable.woff2`
- Font internal version: `Version 4.001;git-9221beed3`
- Variable axes: weight 100–900; optical size 14–32.
- SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`
- License SHA-256: `262481e844521b326f5ecd053e59b98c8b2da78c8ee1bdbb6e8174305e54935a`

The full upstream font includes Cyrillic; it has not been subsetted or converted.
The original `LICENSE.txt` is copied verbatim from the same release archive.
The asset supplies normal variable weights, including the Flood 400/500 roles;
italic text needs a separate face or an explicitly documented fallback.
