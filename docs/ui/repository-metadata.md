# Метаданные рядом с названием

[Индекс](README.md) · уточнение D-01-META, 2026-09-19 · [превью](recipes/flows.html).

Причина: в телефонном просмотре «Приватный/Публичный/Подключён» находились под описанием и читались как его продолжение. Владелец попросил перенести их вправо от названия, не менять остальной язык.

## Контракт

1. Строка имеет три части: selection control; блок **owner/repository + краткие признаки**; отдельное описание под этим блоком.
2. На достаточной ширине признаки справа от имени. На узкой ширине или при длинном имени они переносятся внутри блока заголовка, но **всегда перед описанием**, не после него. Имя и owner не исчезают ради размещения меток.
3. Privacy показывается всегда: «Приватный» либо «Публичный». «Подключён», «Архивный» и «Нет доступа» — независимые дополнительные факты, не альтернативы из одного ternary. Приватный подключённый источник показывает оба признака.
4. «Подключён» появляется после подтверждённого binding, а не после выбора radio или при неизвестном исходе записи. Подключение источника не доказывает разрешение агенту изменять его.
5. Признаки — небольшие нейтральные inline labels: 12/16, обычный вес, тонкий edge, radius 5 и inset 1×6 в этом образце. Нет цветного фона, теней и hover-состояний. Они не кнопки, не попадают в Tab и не содержат ссылок внутри radio label.
6. Лёгкая рамка отделяет категориальный признак от prose; это не разрешение превращать даты, описание и каждое поле JSON в badges. Контраст текста обеспечивается отдельно от декоративного края.
7. Между частями заголовка gap 4×8; между метками 4×6; между заголовком и описанием 6. Описание выровнено с именем, не с radio. Вся строка сохраняет единую область выбора и прежний focus contract.
8. Нет постоянной фиксированной высоты. Перенос, большой текст и несколько совместимых признаков увеличивают строку; горизонтальная прокрутка не появляется.
9. Forced colors сохраняет системные цвета; на выбранной строке текст меток использует цвет выбранного состояния, а не исходный muted token.

## Пример отношений

```text
( ) owner/repository                Приватный   ✓ Подключён
    Описание репозитория отдельной строкой.

Узко / длинное имя:
( ) owner/very-long-repository-name
                         Приватный   ✓ Подключён
    Описание репозитория отдельной строкой.
```

Не заменять длинные имена случайным сокращением и не скрывать visibility при linked/archived/error. Количество меток определяется существующими фактами, не желанием заполнить правый край.

## Проверка

Light/dark; обычное имя и длинный owner/repository; private/public; linked+private; archived+public; revoked+private; filtered selection; pending/unknown без ложного «Подключён». Проверить 1180/780/414/390/320 CSS px, перенос внутри heading, отсутствие overflow и Tab только по настоящим controls.

Изменены только `flows.css` и `flows.js` изолированной лаборатории. [Результаты и ограничения](recipes/repository-metadata-checks.md). В production правило применяется через существующие data/permission contracts, не через импорт demo timers или fixtures.
