## Меньше управления. Больше работы.

Открой проект, посмотри, что требует внимания, и продолжай работать. В повседневном интерфейсе flood.md — переключатель проектов, карточки задач и командный док.

Используй приложение для записи и просмотра задач или оставайся в своём агенте и управляй работой через MCP. В обоих случаях источник данных один — локальные Markdown-файлы.

- **Рабочая зона без перегруза.** Тёмная тема, фильтры открытых, срочных и закрытых задач, редактор с подзадачами и зависимостями.
- **Командный док.** Открывается по `Ctrl+K`. Через `/` доступны быстрые действия; к сообщению можно прикрепить задачу и отправить его в выбранный разговор с агентом.
- **Контекст проекта.** Заметки и необязательные источники; ты выбираешь, что разрешено читать агенту.
- **Твои файлы.** Читаемый Markdown, стабильные идентификаторы, проверка конфликтов, атомарная запись и корзина с восстановлением. Основная работа с задачами доступна без сети.
- **English и Русский.** Для новых установок по умолчанию включён английский; язык меняется в настройках.

## Начать работу

1. Установи [последнюю версию для Windows](https://github.com/tillwithered/flood.md/releases/latest).
2. Создай проект: достаточно названия. Добавь первую задачу — агент и внешние аккаунты не обязательны.
3. Для работы с агентом открой **Настройки → Агент** и подключи Codex. flood.md ищет установленный исполняемый файл автоматически; при необходимости его можно выбрать вручную. Если потребуется, пройди авторизацию.
4. Создай разговор в Codex и выбери его в flood.md. Выбор сохраняется для проекта. Открой док по `Ctrl+K`, при необходимости прикрепи задачу и отправь запрос.

**Сейчас встроено подключение ChatGPT / Codex.** Других встроенных подключений агентов пока нет. Автоматическое создание разговоров Codex ещё не поддерживается: сначала создай разговор в Codex. Запросы агенту расходуют лимиты твоего аккаунта и требуют соединения.

## Работай из своего агента

В установщик входит локальный MCP-сервер `flood-mcp.exe`. Совместимый клиент может работать с проектами, задачами и разрешённым контекстом. При подключении Codex регистрируется MCP flood.md; другие локальные stdio-клиенты требуют отдельной настройки.

Например:

> Покажи срочные задачи проекта сайта. Прочитай контекст первой и предложи следующий шаг.

MCP служит интерфейсом для внешних агентов; встроенная отправка из дока сейчас работает с Codex. Подробности протокола и настройки клиентов — в [руководстве по MCP](docs/mcp.ru.md).

## Необязательные источники

Обсуждения Telegram, GitHub-репозитории с доступом только на чтение, локальные папки и заметки могут дополнять контекст. Они не нужны для базовой работы с проектами и задачами. Добавление источника само по себе не разрешает агенту читать его.

## Твои данные

Проекты и задачи хранятся в Markdown с явными метаданными YAML:

```text
projects/<project-id>/project.md
projects/<project-id>/tasks/<task-id>.md
```

Папка данных Windows по умолчанию — `%APPDATA%\io.flood.desktop`; её можно переопределить через `FLOOD_DATA_DIR`. Собственный аккаунт flood.md и облачный сервер не требуются. Отправка запроса или предоставление доступа агенту может передать выбранный контекст его провайдеру. Локальное хранение не означает, что облачный агент работает без сети.

Правила хранения учётных данных и модель доверия описаны в [SECURITY.md](SECURITY.md).

## Разработка

Потребуются Node.js 22, стабильный Rust и [зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

~~~powershell
npm install
npm run tauri dev
~~~

Официальные релизы получают защищённые параметры Telegram и updater через GitHub Actions. В самостоятельной сборке можно оставить <code>TG_API_ID</code> и <code>TG_API_HASH</code> пустыми и ввести собственные параметры в приложении.

~~~powershell
npm run check
cargo test --workspace
npm run tauri build
~~~
